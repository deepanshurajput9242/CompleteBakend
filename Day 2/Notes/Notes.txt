Frontend (Client)
User se input leta hai.
Server ko request bhejta hai.
Server se response receive karta hai.
Examples:
React
HTML/CSS/JS
Angular
Vue
Backend (Server)
Request receive karta hai.
Data process karta hai.
Database se data fetch/store karta hai.
Response frontend ko bhejta hai.
User
   ↓
Frontend
   ↓ Request
Backend(Server)
   ↓
Database
   ↑
Response

4. REST API

REST = Representational State Transfer

REST API HTTP methods ka use karke server se communicate karti hai.

5. HTTP Methods
GET

Purpose

Server se data lena.

Example

GET /notes

Use Cases

Fetch notes
Fetch users
Fetch products

Status Code

200 OK
POST

Purpose

Server par naya data create karna.

Example

POST /notes

Body

{
   "title":"DSA",
   "description":"Practice daily"
}

Status Code

201 Created
PATCH

Purpose

Existing data ka sirf kuch part update karna.

Example

PATCH /notes/2

Body

{
   "description":"Updated Description"
}

Status

200 OK
PUT

Purpose

Pure object ko replace/update karta hai.

Example

PUT /notes/2

Body

{
   "title":"Java",
   "description":"Java Notes"
}

Difference

PATCH

→ Sirf required field update

PUT

→ Pura object replace

DELETE

Purpose

Data delete karna.

Example

DELETE /notes/2

Status

200 OK

8. Request Object

User ka bheja hua data.

Example

{
"title":"Java"
}

Access

req.params

Dynamic URL values.

Route

app.delete("/notes/:index")

URL

localhost:3000/notes/2

Access

req.params.index

Output

2
req.query

Example

localhost:3000/users?page=2

Access

req.query.page

Output

12. Notes API
POST
app.post("/notes",(req,res)=>{

notes.push(req.body);

res.status(201).json({

success:true,

message:"Note Added"

});

});
GET
app.get("/notes",(req,res)=>{

res.status(200).json({

data:notes

});

});
DELETE
app.delete("/notes/:index",(req,res)=>{

const index=req.params.index;

delete notes[index];

res.status(200).json({

message:"Deleted"

});

});
PATCH
app.patch("/notes/:index",(req,res)=>{

const index=req.params.index;

notes[index].description=req.body.description;

res.status(200).json({

message:"Updated"

});

});

15. Common Errors
❌ Cannot GET /notes

Reason:
Route exist nahi karta.

❌ Cannot PATCH /notes/2

Reason:
PATCH route missing ya URL galat.

❌ req.body undefined

Reason:
Middleware missing.

app.use(express.json());
❌ ReferenceError: exress is not defined

Reason:
Spelling mistake.

Correct

express.json()
❌ Cannot find module

Reason

File path galat
File exist nahi karti
require() path incorrect hai
